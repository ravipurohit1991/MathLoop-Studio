## Description

What if a handful of circles could become your next video?

Meet MathLoop Studio: a free, open-source creative coding studio that turns
Fourier mathematics into animated films. Start with 15 authored 2D and 3D
films, edit the chapters, add an original synthesized soundtrack, and export
your own MP4. You can also import SVG outlines, arrange sculptures in 360°,
and explore photographic Nature Worlds.

CODE + README:
https://github.com/ravipurohit1991/MathLoop-Studio

DOWNLOAD THE DEMO VIDEOS:
https://github.com/ravipurohit1991/MathLoop-Studio/releases/tag/v0.1.0

Get started:
1. Clone the repository.
2. Run npm ci, then npm run dev.
3. Open http://127.0.0.1:5180 and choose a film.

Node.js 22+ is recommended. Native rendering uses FFmpeg and ffprobe.
Browser export needs compatible WebCodecs support. See the README for setup
and the spatial-audio limitations of some browser encoders.

In this video:
00:00 Circles become creatures
00:10 Fifteen authored films + Story Studio
00:28 How the code works
00:38 Import SVGs + synthesized soundtracks
00:54 Build a 360° world
01:06 Nature Worlds
01:16 Clone, remix and render

Built with JavaScript, React, Canvas, WebGL, Fourier transforms, WebCodecs,
and FFmpeg. The music is generated by the project's Aurora Glass score.
Narration is synthesized. Nature photography: Poly Haven, CC0; full credits
are included in the repository.

Star the repo if you would like to see more mathematical films. What should
we turn into a Fourier animation next?
